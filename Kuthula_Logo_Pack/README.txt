WHICH FILE TO USE
- Websites, apps, screens: SVG (scales perfectly) or PNG
- Print / signage / printers: PDF from 5_Print_PDF (or SVG)
- Word / PowerPoint / email: PNG (transparent) or the white-background JPG
- Dark backgrounds: *_Reversed_OnDark   Coloured backgrounds: *_White or *_Black
